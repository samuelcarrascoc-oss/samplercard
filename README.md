# samplercard

Vitrina de **samplercard** (Pokémon TCG, Estación Central, Chile): cartas sueltas, decks, accesorios y sellado.

- Precios y stock se toman del catálogo público de la tienda en [TCGMatch](https://tcgmatch.cl/@samplecard) cada ~15 minutos (`scripts/sync.py` + GitHub Action).
- Compra por WhatsApp o directo en TCGMatch.
- Producto sellado (que no está en TCGMatch): `data/sellados.json`.
